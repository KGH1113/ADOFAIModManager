# TUF difficulty icons

These 75 original PNG icons were downloaded from The Universal Forums on October 24, 2026 for the onboarding introduction.

- Metadata source: https://api.tuforums.com/v2/database/difficulties
- Original images: the `icon` URLs returned by that endpoint, hosted under `https://api.tuforums.com/cdn/images/difficulty_icon/`.
- Difficulty guide: https://the-universal-forums.notion.site/Main-Difficulty-System-PGU-3ca484d6071f8067a0fbeabf5ca2904d
- `sources.json` records each canonical filename, original API name, color, type, and source CDN URL.

The files include P1–P20, G1–G20, U1–U20, GQ0–GQ4, UQ0–UQ4, P0, Qq, Unranked, Censored, and Impossible. Quantum filenames omit the parenthesized estimated range from the API display name. Image content has not been modified.

PGU is a scale of 60 exact ratings across Planetary, Galactic, and Universal tiers. Quantum ratings describe estimated ranges: Q0 corresponds to 1–4 within its tier, Q1 to 5–8, Q2 to 9–12, Q3 to 13–16, and Q4 to 17–20. Qq indicates unknown difficulty rather than an additional PGU tier.
