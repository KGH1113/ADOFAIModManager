# 0.2.5 배포 검증

검증일: 2026-11-10 (KST)

## 배포 결과

- [v0.2.5 정식 릴리스](https://github.com/KGH1113/ADOFAIModManager/releases/tag/v0.2.5)를 2026-11-10 12:33:36 KST에 최신 릴리스로 공개했다. 초안과 사전 릴리스가 아니다.
- 앱 빌드 커밋: `9cef8cb`, 태그: `v0.2.5`.
- macOS Intel(x64, macOS 12 이상) 빌드를 처음 배포했다. Apple Silicon 빌드는 기존과 같이 macOS 14 이상이다.
- 자동 업데이트 서명은 `latest.json`에만 포함하고 `.sig` 파일은 올리지 않는다. 공개 파일은 DMG 2개, Windows 설치 파일, AppImage, macOS 업데이트 압축 파일 2개, `latest.json`으로 7개다.

## 배포 파일 검증

- 공개 전 초안의 업데이트 파일 4개를 내려받아 앱에 내장된 공개키로 검증했다. 키 ID, 파일 서명, trusted comment 서명, 서명된 버전 `0.2.5`가 모두 일치했다.
- macOS 업데이트 압축 파일의 내용:

  | 빌드 | 앱 실행 파일 | 설치 엔진 | `LSMinimumSystemVersion` |
  | --- | --- | --- | --- |
  | Apple Silicon | arm64, minos 14.0 | arm64, minos 14.0 | 14.0 |
  | Intel | x86_64, minos 12.0 | x86_64, minos 12.0 | 12.0 |

- 두 앱 모두 `codesign --verify --deep --strict`를 통과했다. Intel DMG 안의 앱 실행 파일은 Intel 업데이트 압축 파일과 SHA-256이 같았다.
- 배포된 Intel 앱의 설치 엔진으로 Rosetta에서 프로토콜 검사(한글 경로, 페이로드 조회, 상태, 프리셋, 온보딩, ZIP 가져오기, 토글, 삭제, 백업)를 통과했다. 포함된 Harmony 페이로드에는 `exhelper_macos_x86_64.dylib`가 들어 있다.
- 공개 후 [정식 업데이트 매니페스트](https://github.com/KGH1113/ADOFAIModManager/releases/latest/download/latest.json)가 `0.2.5`를 제공하며 검증한 초안과 내용이 같음을 확인했다. 네 플랫폼 다운로드 URL 모두 HTTP 200을 반환했다.

## 검증하지 않은 항목

- 실제 앱에서 0.2.4 → 0.2.5 업데이트·재시작은 이번에 GUI로 확인하지 않았다. Apple Silicon 업데이트는 파일 이름만 바뀌었고, 매니페스트 URL·서명·업로드 파일 대조로 확인했다.
- Intel 빌드는 실제 Intel Mac에서 실행하지 않았다. 게임에 UMM 설치와 모드 로딩은 Intel 실기기에서 확인이 필요하다.
- Intel 자동 업데이트는 다음 릴리스에서 처음 실제로 동작한다.
- Windows/Linux는 CI·서명·다운로드 URL로 검증했다. 해당 OS의 GUI 설치·재시작은 이 환경에서 검증하지 않았다.
