# ADOFAI Mod Manager 0.2.1

## 변경 사항

- 앱을 처음 실행할 때만 시작 가이드를 자동으로 표시합니다. 설정에서 다시 열 수 있습니다.
- 모드 찾기에서 `Info.json`의 ID·이름·홈페이지를 기준으로 기존 설치를 감지합니다. 같은 버전은 설치됨으로 표시하고, 다른 버전은 계속 설치할 수 있습니다.
- 설치 완료 버튼의 색상과 체크 표시를 정리하고 중복 설치 상태 배지를 제거했습니다.
- TUF 소개 문단과 번역을 정리하고, Galactic·Universal 선택 색상을 난이도 아이콘과 맞췄습니다. Planetary와 같은 버튼 스타일을 PGU·Quantum에 적용합니다.
- TUF 소개에 ADOFAI Community Server와 TUF 자료실 링크를 추가했습니다.
- 커뮤니티·자료실 안내를 한국어·영어·중국어 모두 직접적인 설명으로 수정하고 제공된 로고를 적용했습니다.
- Keyboard Chatter Blocker 소개의 불필요한 설정 안내 문구를 제거했습니다.

## 업데이트

자동 업데이트를 지원하는 0.2.0 설치본은 기존 업데이트 채널에서 0.2.1을 받습니다. 지원 대상은 macOS Apple Silicon, Windows x64, Linux x64 AppImage입니다.

앱 시작 시 업데이트를 확인하고 설치합니다. 실행 중에는 설정의 업데이트 확인을 사용할 수 있으며, 다운로드가 완료되면 재시작해 적용할 수 있습니다.
