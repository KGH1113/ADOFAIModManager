# ADOFAI Mod Manager 0.2.4

## 변경 사항

- 스페인어(라틴아메리카)를 추가했습니다. 온보딩, 모드 탐색, 설정, 로그, 단축키 안내를 스페인어로 사용할 수 있습니다. ([#5](https://github.com/KGH1113/ADOFAIModManager/pull/5), @LeninAsto)
- UnityDoorstop 방식으로 설치된 UMM을 인식하도록 개선했습니다. 활성화된 Doorstop 설치가 있으면 게임 어셈블리를 추가로 패치하지 않고 UMM 파일을 갱신하며, 두 주입 방식이 함께 감지되면 경고합니다. ([#3](https://github.com/KGH1113/ADOFAIModManager/pull/3), @memsys-lizi)
- Windows·Proton·Linux·macOS의 Doorstop 설정과 Steam 실행 경로를 확인해 설치 상태를 판단합니다. 비활성화된 설정이나 실제 게임 실행에 사용되지 않는 Unix 실행 스크립트는 활성 설치로 처리하지 않습니다.
- UMM 제거 시 해당 UMM을 가리키는 Doorstop 파일을 백업한 뒤 정리합니다. BepInEx 등 다른 로더를 가리키는 Doorstop 파일은 유지합니다.
- Linux AppImage 업데이트 파일을 재포장한 뒤에도 서명에 앱 버전 정보를 포함하도록 수정해 자동 업데이트 검증 실패를 방지했습니다.

## 업데이트

0.2.0 이상 설치본은 기존 업데이트 채널에서 0.2.4를 받습니다. 지원 대상은 macOS Apple Silicon, Windows x64, Linux x64 AppImage입니다.
