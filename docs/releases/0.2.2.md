# ADOFAI Mod Manager 0.2.2

## 변경 사항

- Linux: 일부 Wayland 환경(Fedora 등)에서 `Could not create default EGL display: EGL_BAD_PARAMETER` 오류로 실행되지 않던 문제를 수정했습니다. AppImage에 포함되던 `libwayland-client`를 제거해 시스템 라이브러리를 사용합니다.
- Linux: WebKitGTK의 DMA-BUF 렌더러를 비활성화해 그래픽 드라이버 관련 렌더링 오류를 줄였습니다.
- Linux: 모드 찾기에서 이모지가 포함된 모드 정보를 표시할 때 앱이 멈추던 문제를 완화했습니다. 컬러 이모지 폰트 대신 내장 흑백 이모지 폰트를 사용합니다.

## 업데이트

0.2.0 이상 설치본은 기존 업데이트 채널에서 0.2.2를 받습니다. 지원 대상은 macOS Apple Silicon, Windows x64, Linux x64 AppImage입니다.
