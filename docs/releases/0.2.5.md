# ADOFAI Mod Manager 0.2.5

## 변경 사항

- Intel Mac을 지원합니다. Intel 전용 설치 파일(`_x64.dmg`)을 새로 제공하며, macOS 12 (Monterey) 이상을 실행하는 Intel Mac에서 사용할 수 있습니다. macOS 12·13에서는 화면이 올바르게 표시되도록 소프트웨어 업데이트로 Safari를 최신 상태로 유지해 주세요.
- 릴리스 다운로드 목록을 정리했습니다. 자동 업데이트 서명은 업데이트 정보(`latest.json`)에 포함되므로 별도의 `.sig` 파일을 더 이상 올리지 않습니다.

## 설치 파일

| 환경 | 파일 |
| --- | --- |
| macOS Apple Silicon (macOS 14 이상) | `ADOFAI.Mod.Manager_0.2.5_aarch64.dmg` |
| macOS Intel (macOS 12 이상) | `ADOFAI.Mod.Manager_0.2.5_x64.dmg` |
| Windows x64 | `ADOFAI.Mod.Manager_0.2.5_x64-setup.exe` |
| Linux x64 | `ADOFAI.Mod.Manager_0.2.5_amd64.AppImage` |

`.app.tar.gz`와 `latest.json`은 자동 업데이트용 파일이므로 직접 받을 필요가 없습니다.

## 업데이트

0.2.0 이상 설치본은 기존 업데이트 채널에서 0.2.5를 받습니다. Intel Mac은 이번이 첫 배포이므로 `_x64.dmg`로 설치하면 다음 버전부터 자동 업데이트됩니다. 지원 대상은 macOS Apple Silicon·Intel, Windows x64, Linux x64 AppImage입니다.
