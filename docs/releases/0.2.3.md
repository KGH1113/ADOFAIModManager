# ADOFAI Mod Manager 0.2.3

## 변경 사항

- Windows: 사용자명이나 설치 경로에 한글 등 비ASCII 문자가 포함되면 동봉된 DLL을 찾지 못해 UMM 설치가 `Could not resolve UnityModManager payload files.` 오류로 실패하던 문제를 수정했습니다. 앱과 설치 엔진 사이의 요청 및 응답 인코딩을 UTF-8로 고정했습니다.
- 한글 경로에서 게임과 동봉 DLL을 찾는 회귀 검사와 Windows 입력 인코딩 진단 스크립트를 추가했습니다.

## 업데이트

0.2.0 이상 설치본은 기존 업데이트 채널에서 0.2.3을 받습니다. 지원 대상은 macOS Apple Silicon, Windows x64, Linux x64 AppImage입니다.
