# UMM 설치 후 사용 안내 화면 개편 계획

## 목표

현재 `Configure your mods in-game` 화면을, UMM 설치를 마친 사용자가 모드 메뉴를 여는 방법을 자연스럽게 배우는 안내 화면으로 바꾼다. 첫눈에 기억할 정보는 **게임에서 Ctrl + F10을 누르면 모드 메뉴가 열린다**는 한 가지다.

분위기는 현재의 어두운 배경과 라임색 포인트를 유지한다. 설치 완료를 짧게 확인해 주고, 단축키를 크게 보여 주는 차분한 사용 안내로 구성한다. 이 단계에서 사용자가 실제로 게임을 실행하거나 설정을 완료해야 다음으로 넘어가는 것처럼 보이지 않게 한다.

## 권장 문구

| 위치 | 한국어 | English |
| --- | --- | --- |
| 상단 작은 문구 | UMM 설치 완료 | UMM INSTALLED |
| 제목 | 이제 모드 메뉴를 열 수 있어요 | You can now open the mod menu |
| 설명 | 얼불춤을 실행한 뒤 Ctrl + F10을 눌러 보세요. | Launch A Dance of Fire and Ice, then press Ctrl + F10. |
| 중심 시각 요소 | `Ctrl` + `F10` 키캡 | `Ctrl` + `F10` keycaps |
| 보조 안내 | 모드 메뉴에서 설치된 모드의 설정을 바꿀 수 있어요. | Use the mod menu to adjust settings for your installed mods. |
| 다음 버튼 | 알겠어요 | Got it |

사용자가 제시한 영어 표현은 `know` 대신 `now`가 맞으며, 위 문구로 자연스럽게 다듬는다. `UMM 설치 완료`라는 상태 문구는 실제 설치 성공 후 진입하는 단계인지 확인한 뒤 적용한다.

## 화면 구성

1. 왼쪽 미디어, 오른쪽 안내라는 기존 큰 틀을 유지한다.
2. 오른쪽은 **설치 완료 → 메뉴를 열 수 있다는 제목 → 게임 실행 안내 → 큰 단축키 → 설정 안내 → 다음 버튼** 순서로 읽히게 한다.
3. 기존 01·02·03 번호 목록은 없앤다. 단축키를 설명의 두 번째 항목에서 화면의 핵심 시각 요소로 끌어올린다.
4. `Ctrl`과 `F10` 키캡은 제목 아래 안내에 붙여 배치하고, 충분한 여백과 크기로 기억하기 쉽게 만든다. 클릭 가능한 버튼처럼 작동시키지는 않는다.
5. 효과 제거 관련 문장은 기본 설명에서 덜어낸다. 이 화면은 메뉴를 여는 방법을 알려주는 데 집중하고, 특정 모드의 옵션은 별도 안내가 필요한 경우에만 넣는다.
6. 왼쪽 영상은 게임에서 단축키를 누른 뒤 UMM 메뉴가 열리는 순간을 보여 주는 역할로 유지한다. 첨부 화면에서는 빈 영역으로 보이므로 실제 미디어 소스·로딩·실패 상태를 확인한다. 영상이 없거나 재생되지 않으면 빈 테두리 대신 사용 가능한 실제 메뉴 이미지나 간결한 안내를 표시한다. 새 촬영이 필요한 경우는 별도로 기록한다.
7. 다음 버튼은 `Understand`에서 `Got it`으로 바꾼다. 버튼은 기존 다음 단계로 이동하며 게임 실행이나 실제 키 입력을 요구하지 않는다.

## 움직임과 접근성

- 기존 화면 전환에 맞춰 제목, 단축키, 보조 설명이 짧게 나타나도록 한다. 키캡을 반복해서 깜박이는 효과는 넣지 않는다.
- 영상에 키 입력 강조를 추가할 경우 메뉴가 열리는 순간과 동기화한다. 실제 영상 확보 여부에 따라 선택 사항으로 둔다.
- 키캡을 기존 `kbd` 요소로 유지하고, 작은 화면에서는 미디어와 안내를 세로로 배치한다. 모션 감소 설정과 긴 한국어 문구도 고려한다.

## 구현 순서와 대상

1. `frontend/src/pages/onboarding/onboarding-page.tsx`와 온보딩 상태 모델에서 UMM 설치 성공 후 이 화면으로 넘어오는 조건을 확인한다.
2. `frontend/src/i18n/locales/en/common.json`, `frontend/src/i18n/locales/ko/common.json`의 `onboarding.modSettings.*` 문구를 변경한다.
3. `frontend/src/components/onboarding/setup-guides.tsx`의 `ModSettingsGuide`에서 번호 목록을 단축키 중심 안내로 재구성한다. 필요한 스타일만 조정한다.
4. `frontend/src/components/onboarding/preview-video.tsx`의 `modSettings` 미디어와 대체 표시를 확인한다.
5. `frontend/src/app/app-root.test.tsx`의 제목과 버튼 기대값을 갱신하고, 기존 온보딩 이동 검증을 실행한다.
6. 영어·한국어, 기본 데스크톱 크기·작은 창, 미디어 정상·미디어 실패 상태를 시각적으로 확인한다.

## 완료 기준

- 화면을 몇 초만 보아도 설치가 끝났고 게임에서 Ctrl + F10으로 모드 메뉴를 열 수 있음을 이해한다.
- 모드 설정을 당장 완료해야 하는 필수 작업처럼 느껴지지 않는다.
- 제목, 키캡, 영상이 같은 사용법을 설명하며 긴 번호 목록이 시선을 분산하지 않는다.
- 한국어와 영어에서 문구가 잘리거나 버튼이 화면 밖으로 밀리지 않는다.
- 기존 다음·뒤로 이동 동작과 온보딩 흐름이 유지된다.

## 구현 결과 (2026-10-02)

- 설치 성공 후 진입하는 기존 흐름을 확인하고, 설치 완료·메뉴 열기 중심으로 문구를 변경했다. 한국어·영어·중국어의 번역 키와 안내 내용을 함께 맞췄다.
- 번호 목록과 효과 제거 설명을 없애고, 설치 상태·제목·게임 실행 안내·설정 안내·확인 버튼으로 단순화했다.
- `modSettings.mp4` 파일이 현재 없으므로 왼쪽에는 큰 Ctrl + F10 키캡과 메뉴 열기 안내를 표시한다. 향후 영상 파일이 추가되면 영상이 표시되고, 영상 로드 실패 시에도 키캡으로 대체한다. 실제 영상의 정상 재생·실패 시나리오는 파일이 없어 브라우저에서 검증하지 않았다.
- 작은 창에서는 미디어 영역의 높이를 줄여 확인 버튼이 화면 안에 보이도록 했다. 기존 화면 전환과 모션 감소 처리는 유지한다.
- 확인: `bun run check`의 타입 검사·Biome 검사 및 전체 49개 테스트 통과. 브라우저 샘플 데이터에서 영어·한국어 화면, 640 × 720 창의 버튼 노출, “알겠어요” 클릭 후 다음 단계 이동을 확인했다. 브라우저 오류 로그는 없었다.
