# Hand illustration asset

The onboarding hand uses the MIT-licensed `generic-hand/left.glb` mesh from [WebXR Input Profiles](https://github.com/immersive-web/webxr-input-profiles/tree/main/packages/assets). Its geometry and skin weights are bundled locally; no network or hand tracking is used at runtime.

SHA-256: bc67783144944ea1cda54d9247885825ea5fb9d4651469fe7d00be517a5c2b87

The source asset is [left.glb](https://cdn.jsdelivr.net/npm/@webxr-input-profiles/assets@1.0/dist/profiles/generic-hand/left.glb). The derived geometry is `hand-geometry.json`. `scripts/read-hand-geometry.py` reads the original GLB into that representation.
